# Bill K Official — Professional Website Upgrade

A responsive static artist website for GitHub Pages.

## Included

- Professional responsive layout
- Mobile navigation with accessible controls
- SEO title, description, canonical URL and robots directives
- Open Graph and Twitter sharing metadata
- Music artist structured data (JSON-LD)
- TESTIMONY OF GRACE tracklist
- Mulokole featured as a current single
- The Journey catalog section
- YouTube, Spotify, Boomplay and Audiomack links
- Booking/contact section
- Social links
- Accessibility improvements
- `robots.txt`
- `sitemap.xml`

## Deploy

Upload the contents of this folder to the root of your GitHub Pages repository. Keep the `assets/` folder and its files alongside `index.html`.

The site remains a no-build static website.

## Important

The existing public contact numbers and social/streaming URLs supplied in the original site were retained. Verify every contact number and external profile URL before publishing.

The canonical URL is currently:
https://billkofficial.github.io/BillKOfficial/

If you later connect a custom domain, update the canonical URL, Open Graph URL, JSON-LD URL, robots.txt sitemap URL, and sitemap.xml.
